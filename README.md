# Thesis Management System

CS0053 final project (C++ console application), Section TN33, Group [5].

## Purpose

A console program that manages thesis proposals through their whole review
cycle. A **student** submits and maintains a proposal, an **adviser** reviews
it (approve, reject, comment), and a **repository** view lets anyone browse
approved and rejected theses, search, sort, and see statistics. All records are
saved to a text file so they are still there the next time the program runs.

## Features

**Student menu**
- Submit Proposal: creates a record with an auto-generated ID (`TH-001`, `TH-002`, ...), status `Pending`
- View Proposal: shows full details of one thesis by ID
- Edit Proposal: changes the title
- Delete Proposal: removes a thesis
- Submit Revision: sets the status back to `Pending` for another review
- Check Status: shows the current status of one thesis

**Adviser menu**
- Review Theses: lists all theses (ID, student, title, status)
- Approve Thesis / Reject Thesis: sets the status to `Approved` or `Rejected`
- Add Comment: stores the adviser's comment on a thesis

**Thesis Repository menu**
- View Accepted Theses / View Rejected Theses
- Search Thesis: keyword search in titles (not case-sensitive)
- Sort By Title: sorts the stored list alphabetically (not case-sensitive)
- Display Statistics: counts of Approved, Rejected, Pending, and Total

**General**
- Menu input is validated: typing a letter or an empty line re-asks instead of looping or crashing
- Data is saved to `theses.txt` after every menu action and loaded when the program starts

## Requirements

- A C++ compiler with C++11 or newer. The project was built with **g++ (GCC, MinGW-w64 / MSYS2 UCRT64)** and also compiles with a Linux g++ using `-std=c++17`
- No external libraries (standard library only)
- VS Code is optional

## Compile and run

Open a terminal in the folder that contains `cs0053_finalproject.cpp`.

**Windows (PowerShell or VS Code terminal)**

```
g++ -std=c++17 -Wall -Wextra cs0053_finalproject.cpp -o finalproject
.\finalproject.exe
```

**Linux / macOS**

```
g++ -std=c++17 -Wall -Wextra cs0053_finalproject.cpp -o finalproject
./finalproject
```

The compile command should print nothing. Run the program from the same folder
every time: `theses.txt` is created and read in the folder you start it from.

Common problems:
- `Permission denied` / `cannot open output file finalproject.exe`: the old copy is still running or locked. Close it, or run `taskkill /IM finalproject.exe /F`, then compile again
- "Application Control policy blocked this file": a Windows security setting is blocking the compiled `.exe`; this is not a code problem

## Saved data format (`theses.txt`)

Plain text, one field per line. Line 1 is the next thesis number, line 2 is the
number of records, then 6 lines per thesis: ID, student, title, adviser,
status, comments.

```
2
1
TH-001
Von San Juan
Smart Library System
Dr. Cruz
Approved
Add more references
```

Do not edit this file by hand. It is read by line position, so one missing or
extra line makes the program print a warning and start with no records.
`theses.txt` is listed in `.gitignore` and should not be committed.

## Known limitations

- There is no login: anyone can open any menu
- Submit Revision only resets the status to `Pending`; it does not change the thesis text
- A thesis that is already `Approved` can still be approved, rejected, or revised again
- Sort By Title reorders the stored list but does not print it; use Review Theses to see the new order
- IDs of deleted theses are not reused
